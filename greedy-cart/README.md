# 🛒 Greedy Cart

Greedy Cart is an e-commerce website project created as part of my web development learning journey.

## About the Project

This project focuses on practicing website structure and creating webpages for an online shopping experience using HTML and CSS.

## Pages

- Home
- Products
- Product Details
- Wishlist
- Cart
- Checkout

## Technologies Used

- HTML5
- CSS3

## Learning Objectives

- Build structured webpages for an e-commerce website.
- Practice organizing multiple HTML pages.
- Work with images and website assets.
- Improve webpage layouts and styling.
- Strengthen frontend development fundamentals.

## Future Improvements

- Create a responsive layout for different screen sizes.
- Add interactive features using JavaScript.
- Improve the shopping experience and visual design.
